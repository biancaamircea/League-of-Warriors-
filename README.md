# League of Warriors

Implementation time: 24 hours.

This project implements the graphical interface for League of Warriors together with design patterns.

The interface includes a login screen and a view of available characters. Once the player selects a character, the game board is displayed. When the player reaches an Enemy tile, details about both the character and the enemy are shown, and combat can begin.

A Quit button allows the player to exit the game.

## Running

The game can be tested using the `GameApp` class.
